🎻 Sangeetika — My Personal Music App for organizing and preserving favourite songs.
🎻 Sangeetika

My Personal Music App

Sangeetika is a personal music collection app designed to help me organize, explore, and keep track of my favourite songs.

It provides a simple and beautiful way to store song information such as the singer, lyricist, music director, film/album, year, genre, notes, and personal rating.

---

✨ Features

- 🎵 Add songs to your personal collection
- 🔎 Search songs quickly
- 🎼 Filter songs by genre and year
- ⭐ Rate songs
- ✏️ Edit song information
- 🗑️ Delete songs
- 📖 View complete song details
- 💾 Save songs using browser localStorage
- 📱 Mobile-friendly design
- 🖥️ Works on desktop and mobile
- 📲 Installable as a Progressive Web App (PWA)
- 🎻 Custom teak-wood inspired interface with a violin theme

---

📝 Song Information

Each song can contain:

- Song title
- Genre
- Singer
- Lyricist
- Music
- Album / Film
- Year
- Personal note
- Rating
- Music link (optional)

---

🔐 Privacy

Sangeetika stores the songs added through the app in the browser's localStorage.

This means:

- Your subsequently added songs stay on your device/browser.
- They are not automatically uploaded to GitHub.
- Other people visiting the public website do not automatically see the songs stored in your browser.

⚠️ Important

If personal song data is included directly inside the GitHub repository's source code, that information can be viewed by anyone when the repository is public.

For a public version of Sangeetika, avoid putting private/personal collection data directly into the source code.

📱 Install Sangeetika

Sangeetika can be installed like an app on supported devices.

Android / Chrome

1. Open the Sangeetika website in Chrome.
2. Open the browser menu.
3. Select Install app or Add to Home screen.
4. Sangeetika will appear on your device like an app.
